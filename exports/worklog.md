## 2026-09-22 · v0.9.0-alpha.2 远征与长期成长骨架

- 依据《Endless Rails｜v0.9.0 远征与长期成长系统需求》开始实现长线版本；本轮直接更新 GitHub `main`。
- 新增长期 Meta 模块 `endless-rails/longterm.js`：独立 localStorage 存档、废料/技术组件/研究数据、蓝图、Train Level/XP、无人机长期研究、铁路区域状态、远征编组、风险资源/保底资源和结算规则。
- 新增远征准备界面：主页“开始远征”改为“远征准备”；可选择铁路区域、配置功能车厢、查看长期资源、升级列车和购买无人机研究。
- 第一版铁路网络共 4 区域：起始荒原 → 废墟城市 → 工业区 / 感染区。区域拥有不同 HP、尸潮密度、Elite 与收益倍率；通关解锁后续区域，两次完成后标记修复。
- 第一版列车战略层：机库固定；近防、仓储、雷达、维修可编组。列车等级决定远征车厢上限；废料 + 技术组件可直接强化 Train Level。
- 近防车厢作为低占比自动防御，仅拦截近距离威胁；仓储影响失败时风险资源保留；雷达补充路线风险情报；维修在安全停靠时额外恢复。
- 新增 Continue / Extract 核心闭环：到站会将当前风险资源锁定为保底资源；玩家可继续深入或“安全撤离”。失败默认保留 50% 未锁定资源，携带有效仓储车时保留 70%，相关蓝图可进一步提升。
- 新增长期战场奖励：特殊敌人可掉研究数据，Elite 掉技术组件并有机会掉区域蓝图，普通敌人有少量维修组件掉落；Boss 提供高价值组件、研究数据和区域蓝图。
- 新增/强化主动威胁：冲车感染者高速撞击列车并造成更高冲撞伤害；攀爬感染者会锁定并压制具体功能车厢，击杀后恢复；原酸液喷吐者继续承担远程威胁角色。
- 车厢压制暂不引入每节独立 HP；通过“附着 → 功能暂时失效”验证北辰救火价值，降低首版工程复杂度。
- 北辰操作收益第一版落地：白虹根据同一直线可贯穿目标数获得额外输出；惊蛰在密集尸群中获得连锁伤害增益；烛龙燃烧落点会被北辰当前移动方向牵引，可主动铺设火墙。
- 无人机长期研究：每类无人机有 3 级小型研究线，小幅基础数值成长，Lv.3 解锁专精机制；长期加成在局内武器 profile 上统一结算。
- 首批“局外解锁 → 局内选择”的 Lv.10 测试分支已加入：天隼可选“集束弹头 / 重型弹头”；白虹可选“聚束磁轨 / 双轨齐射”。只有对应长期研究达到 Lv.3 时才在本局 Lv.10 出现。
- 修正一个研究接入问题：天隼发射时不再重新读取未强化的基础 profile，确保长期研究/蓝图加成进入真实攻击。
- Camera 第一版接入：按当前远征编组长度计算 Base Zoom，尸潮高压与 Boss 可额外小幅拉远，使用平滑插值；拉远后敌人出生安全边界同步扩大，区域尸潮密度同步调整。
- 战斗渲染新增车厢功能标识与压制状态；冲车/攀爬/酸液威胁加入简洁识别标记；4 个铁路区域加入基础视觉色调差异。
- 首页版本更新为 `v0.9.0-alpha.2`；关键脚本/样式缓存版本统一为 `20260922-v090a2`；PWA manifest 文案同步更新。
