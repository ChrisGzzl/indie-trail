# Endless Rails v0.4 荒原远征设计

**状态：** 已获用户批准，待实现
**日期：** 2026-09-06
**目标版本：** v0.4

## 目标

在 v0.3 双进度系统上继续提升 Endless Rails 的视觉速度感、手机操控、战斗决策和重复体验。列车持续向前，地面与铁路必须表现为同一个向后移动的世界；无人机操控不要求玩家持续拖住无人机；伴飞单位必须使用独立且有上限的火力预算。

## 体验支柱

1. **速度与追击：** 地面、铁路和世界标记共享运动方向与速度参照，玩家能感知列车正在高速前进且敌人正在逼近。
2. **相对操控：** 玩家点击战场任意位置即可给无人机下达相对列车的指令，不需要精准触碰无人机本体。
3. **有边界的火力成长：** 主无人机、伴飞无人机和列车武器分别计算，升级作用范围明确，伴飞总 DPS 受预算限制。
4. **每局有差异：** 路线事件、远征契约和构筑摘要让玩家有理由尝试下一局，同时保持单局规则容易理解。
5. **移动端可读：** 关键 HUD、升级卡、暂停和结果信息在 390x844 与 320x568 中不遮挡战场且可操作。

## 操控设计

默认输入模式为“相对指令”。触点位置相对于列车中心计算方向和距离，目标位置为列车中心加上限制后的偏移量。单击即可完成定位；短暂拖动只用于连续微调，不要求持续按住无人机。无人机目标半径限制在战场安全范围内，并在触摸期间显示短暂方向环，松开后淡出。

桌面鼠标和手机触摸使用同一套相对坐标函数。保留“直接指向”作为设置项和调试兼容模式，但教程、默认提示和验收均以相对指令为准。输入层必须忽略暂停按钮、脉冲按钮和覆盖层中的点击，不能让 UI 点击改变无人机位置。

## 世界运动和地面表现

列车保持在画面中心，世界物体沿统一的前进向量反向滚动。地面绘制拆为三个层级：

- 近景：碎石、尘土、轨旁短标记和速度线，移动最快；
- 中景：电线杆、废弃标牌、岩块和沙丘，移动速度较慢；
- 远景：地平线、山脉和天气层，移动最慢。

铁路、枕木、地面纹理和近景标记共享滚动方向与相位。地面采用可循环分块和确定性随机标记，避免与列车运动无关的随机背景动画。车站和路线事件只改变地面材质、颜色、天气密度和标记集合，不复制运动逻辑。

高速、沙尘和 Boss 阶段可以提高近景滚动速度、尘土密度和轨旁掠过频率，但地平线保持稳定参照。镜头震动只用于受击、脉冲和 Boss 事件，持续时间短且受 reduced-motion 设置约束。

## 火力模型

火力配置由纯函数生成，并为每项升级声明作用范围：`main-only`、`escort-only`、`train-only` 或 `team-utility`。

### 主无人机

主无人机拥有主要输出和经验升级，包括射速、散射、穿透、链式和导弹。核心效果必须在配置中明确是否作用于主武器或全队，未声明的效果不得自动传递给伴飞单位。

### 伴飞无人机

伴飞单位使用独立伤害、独立冷却和简化弹道：

- 默认单发，不继承主无人机的散射、穿透、链式和导弹；
- 初始单发伤害为主无人机基础单发伤害的 40%；
- 初始射击间隔为主无人机基础射击间隔的 1.35 倍；
- 增加数量主要提升覆盖范围和目标分配，不复制完整主武器升级；
- 全部伴飞共享护航火力预算，总伴飞 DPS 初始上限为主无人机当前 DPS 的 60%；
- 增加伴飞数量时，在共享预算内重新分配单机伤害或射速；
- 只有明确标记为 `escort-only` 的升级可以强化伴飞。

主武器、护航武器和列车武器的 DPS 计算必须能单独测试。测试覆盖主武器升级不会让伴飞无限增长、伴飞数量不会突破预算、护航升级仍有收益，以及同一升级在不同等级下不会重复叠加。

## 路线和复玩

每段路线开始时从三个路线事件中选择一个。首批事件包括沙尘暴、高速冲刺和废弃货运线，分别调整能见度、路线长度、敌人速度、精英率或核心掉落率。每局开始提供三个远征契约，契约改变风险与奖励但不永久改变基础平衡。

每个补给站允许一次消耗废料的重新抽取。结果页展示路线事件、远征契约、升级构筑、核心组合、最高连杀、到达车站和失败原因。使用 `localStorage` 保存最佳记录和简单构筑统计，不加入复杂永久属性成长，先验证路线变化和构筑差异是否带来复玩价值。

## 状态和模块边界

- `game.js`：运行状态整合、Canvas 绘制、DOM、输入和时序；只保留必要的协调逻辑。
- `progression.js`：经验、路线、核心和成长规则。
- `combat-effects.js`：伴飞位置、范围伤害、武器配置和护航预算纯函数。
- `route-events.js`：路线事件、远征契约和确定性修正。
- `run-record.js`：运行种子、结果摘要和本地最佳记录。
- `index.html` / `styles.css`：相对操控提示、暂停、路线事件、结果摘要和移动端布局。

运行种子只用于可复现的路线事件、地面标记和随机抽取；重置运行必须清空本局战斗状态，但保留本地最佳记录。缺失可选脚本时继续使用现有 fallback，不得阻止启动。

## 错误处理和边界

- 暂停时冻结敌人、射击、路线距离、掉落寿命和地面滚动，保留最后一帧画面。
- 覆盖层打开时，战场触摸不能穿透到输入层。
- 核心已满时转化为废料并显示反馈，不静默丢失。
- 伴飞配置缺失或非法时回退为零伴飞，不复制主武器配置。
- reduced-motion 下关闭持续尘土脉冲和大幅镜头震动，保留必要命中反馈。

## 验收标准

### 自动化

- `balance.test.js`、`motion.test.js`、`progression.test.js` 和 `combat-effects.test.js` 全部通过；
- 新增输入、火力预算、路线事件、种子运行、暂停和运行记录测试；
- 所有浏览器脚本通过 `node --check`；
- `git diff --check` 无错误；
- 本地 HTTP 检查确认脚本顺序、静态资源和可选模块 fallback。

### 浏览器试玩

- 在 390x844 和 320x568 下，点击战场任意位置即可调整无人机，手指无需覆盖无人机；
- 地面、铁路和近景标记向后移动，且速度变化与实际路线速度一致；
- 第一段路线出现经验升级，升级暂停战斗并在选择后恢复；
- 伴飞不会复制主无人机完整伤害，增加数量后总伴飞 DPS 仍在预算内；
- 至少三种构筑和两种路线事件能形成可感知差异；
- 暂停、补给站、结果页和重新开始流程不遮挡、不穿透、不残留旧状态。
