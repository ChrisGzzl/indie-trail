# Indie Trail

独立游戏原型合集。

## Pinball

像素风弹珠台与背包构筑 Roguelite Demo，位于 [`pinball/`](./pinball/)。

## Endless Rails

原创竖屏荒原列车防守试玩，拖动无人机守护自动前行的列车，在补给站选择战斗模块，位于 [`endless-rails/`](./endless-rails/)。当前开发版本为 v0.2：5 个车站、第五关 Boss、飞机/列车双升级和可增长车厢。

本地运行：

```powershell
python -m http.server 4173
```

然后打开 <http://127.0.0.1:4173/pinball/>。
