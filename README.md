# Indie Trail

独立游戏原型合集。

## Pinball

像素风弹珠台与背包构筑 Roguelite Demo，位于 [`pinball/`](./pinball/)。

## Endless Rails

原创竖屏荒原列车防守试玩，拖动无人机守护自动前行的列车，在补给站选择战斗模块，位于 [`endless-rails/`](./endless-rails/)。v0.2 是已手动提交的基线版本；v0.3 在此基础上加入战斗经验升级、武器核心拾取，以及路线/经验双进度 HUD。

本地运行：

```powershell
python -m http.server 4173
```

然后打开 <http://127.0.0.1:4173/pinball/>。
