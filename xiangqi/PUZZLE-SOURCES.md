# 残局题库来源

本项目内置的六道杀法练习取自 GitHub 项目
[`benckx/elephantchess`](https://github.com/benckx/elephantchess) 的开发数据集
`dev_dataset.pgsql`。题目由该项目使用 Pikafish 生成或验证，并按一步杀、三步杀、
五步杀分类。

经过验证的主线着法，不包含用户数据或完整开发数据库。
